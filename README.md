## Introduction

This exercise aims to develop an advanced Deep Learning model to predict the engagement level generated by different tourist points of interest (POIs). For this task, two types of data are available:

1. Structured metadata associated with each POI.

2. A representative image of the POI.

The metadata includes several variables related to the POI's engagement metrics.

## Exploratory data analysis (1_EDA.ipynb)

First, a general exploration of the data is performed: number of samples, number of variables, data structure, and presence of NA values.

### Feature 'engagement'

We explore how to create a qualitative variable representing 'engagement' for each sample using engagement-related metrics. A new variable, 'Likes_Dislikes,' is introduced by subtracting 'Dislikes' from 'Likes.'

The distribution of variables is analyzed, revealing similar profiles for 'Likes,' 'Dislikes,' and 'Bookmarks.' Correlation analysis shows strong relationships between these variables. To avoid redundancy, 'Visits' and 'Likes_Dislikes' are selected to compute an engagement 'score'.

The 'Likes_Dislikes' and 'Visits' values are normalized to a [0, 1] range, and the score is calculated as their mean. The resulting score follows a distribution resembling a smoothed Gaussian curve skewed toward higher values. To classify engagement levels (high/low), the median score threshold of 0.29 is applied.

### Representative images of the POI

A random sample of images is displayed alongside their associated engagement scores.

To identify potentially non-representative images (e.g., entirely black or white), the standard deviation (SD) of pixel values is calculated for each RGB channel. The distribution of these SD values reveals images with low variability in one or more channels. Upon visualizing images with SD values below 1 in any channel, clear examples of 'empty' images (e.g., blank/featureless) are observed.

The algorithm will handle these cases automatically, adjusting the model to account for such images during training.

### Feature 'shortDescription'

The 'shortDescription' feature is analyzed by displaying random examples and plotting the distribution of word counts. Most samples contain approximately 19 words per description, though some range from as few as two words to as many as 89.

### Feature 'categories'

For the 'categories' variable, most samples contain three categories, with 'History' being the most common and 'Gastronomy' the least common. Given the relatively low number of unique categories (12), this variable was encoded using one-hot encoding.

### Feature 'tags'

The 'tags' variable exhibits an extremely high number of unique values (2935), making it impractical for modeling. Consequently, this variable was discarded from the model.

### Feature 'tier'

In the 'tier' variable, the most frequent value is 1 and the least frequent is 4. This variable was also encoded as one-hot encoding.

### Quantitative features

Finally, we visualize the distributions of the continuous variables: 'locationLon', 'locationLat' and 'xps'

## Data processing (2_DLA.ipynb)

The samples are distributed into training data, validation data, and test data. From the total dataset, 20% is allocated to test. The remaining 80% is split further, 20% for validation and the rest for training. The engagement variable is calculated after creating these splits, following the methodology described in the Exploratory Data Analysis (EDA).

The same preprocessing is applied to all three datasets (training, validation, and test):

1. New feature creation: Generate a ‘NumTags’ variable (count of tags).

2. Categorical Encoding:

- Apply one-hot encoding to the ‘categories’ variable.

- Apply one-hot encoding to the ‘tier’ variable.

3. Feature Scaling: Scale the continuous variables: ‘xps’, ‘locationLon’, and ‘locationLat’.

The variables 'xps', 'locationLon', 'locationLat', 'Visits', and 'Likes_Dislikes' are scaled using the training data as reference to prevent data leakage. For encoding the 'tier' and 'categories' variables, the complete dataset is used as reference to ensure no categories are lost.

## Methods (2_DLA.ipynb)

The framework used to identify the most effective model is as follows:

1. Parameter and Function Definition: Neural network model architecture, optimizer selection, loss function specification, fixed parameters declaration and parameters to optimize
2. Training Validation: Verification of proper training execution using the defined conditions with training and validation datasets.
3. Hyperparameter Optimization: Systematic parameter tuning via Optuna using training and validation sets.
4. Final Model Evaluation: Implementation of optimal parameters followed by testing on the holdout dataset to assess model performance.

To evaluate the model's effectiveness, accuracy was used as the reference metric. However, a full analysis of the results will be shown (confusion matrix, sensitivity, F1-score) in case other metrics need to be considered. In this scenario, it would be valuable for the model to detect as many high-engagement cases as possible (recall).

The following models will be considered:

1. Fully-connected neuronal network (FCNN)
2. Convolutional neuronal network (CNN)
3. FCNN-CNN Dual-branch neuronal network (FCNN_CNN)
4. Transfer learning neuronal network (Pretrained ResNet18)
5. FCNN-ResNet18 Dual-branch neuronal network (FCNN_RN18)

For these initial models, we will optimize the hyperparameters 'learning rate', 'batch size', and 'dropout rate'. However, we remain open to testing the optimization of other parameters or adding new functionalities during the search for a better model.

## Results (2_DLA.ipynb)

1. Fully-connected neuronal network.

The best parameter combination found during optimization results in a model with 66% prediction accuracy. The optimization shows that the learning rate hyperparameter has significant importance, while batch size has minimal relevance.

The model trained with the optimized hyperparameters is used to predict test values, achieving:

- 67% total accuracy

- High sensitivity (0.85) for high-engagement POIs

- Low sensitivity (0.46) for low-engagement POIs

The loss function and accuracy plots reveal overfitting, with training accuracy reaching around 70%.

2. Convolutional neuronal network

For this network, the combination of hyperparameters with the lowest values leads to significantly lower accuracy (56%) compared to the FCNN network. The most influential hyperparameter is 'dropout_rate', which is higher than in the FCNN network. The 'learning rate' is similar to the one obtained with FCNN. The optimal 'batch_size', though less impactful than 'dropout_rate', is the smallest (32).

When the model is trained with these hyperparameters and run on the test dataset, the resulting total accuracy is 60%, below that obtained for the FCNN network. If we look at the precision values by level and the sensitivity values, for both levels the values are similar. In the representation of the accuracy values as training progresses, it becomes difficult to assess the presence of 'overfitting' due to the unstable behavior. We could try to find better hyperparameters through optimization by allowing lower ranges for the 'learning rate' and 'batch size' hyperparameters.

3. FCNN-CNN Dual-branch neuronal network.

In the optimization of hyperparameters for this model, the three optimized hyperparameters have similar relevance. The 'dropout rate' reaches a high value very close to the limit set in the optimization. The 'learning rate' takes a low value but separated from the lower limit. The most optimal 'batch size' takes as final value the highest available. At the end of the optimization, the most convenient parameter combination makes the model give a validation set accuracy of 65%, close to the value obtained with the FCNN network.

With the most convenient hyperparameters, the model is trained again and applied to the test dataset. A total accuracy of 68% is obtained, slightly above the value obtained for the FCNN network. The accuracy for both 'engagement' levels is similar, while the sensitivity is higher for the high 'engagement' level.

In the representation of the loss function and accuracy for the three training, validation and test sets, very little 'overfitting' is observed. The accuracy for the test set is very similar to the final accuracy obtained with the training set.

A new optimization of the hyperparameters is tested by modifying the limits of 'dropout rate' and 'batch size' to explore the possibility that higher values may be beneficial. The results are similar to the previous experiment. A slightly higher total accuracy of 69% is obtained.

4. Transfer learning neuronal network (Pretrained ResNet18)

The hyperparameters 'learning rate' and 'batch size' in the optimization show approximately the same relevance.

With the best hyperparameters found, the prediction accuracy on the evaluation set is 64%. When using the model trained with these parameters, the total accuracy is 62%, lower than other models like FCNN and the FCNN-CNN dual-branch.

The accuracy plot reveals considerable overfitting, with training accuracy reaching nearly 75%.

5. FCNN-ResNet18 Dual-branch neuronal network

The hyperparameter optimization leads to values that are at central points of the ranges except for 'batch size' which turns out to be the lowest available value (32). All optimized hyperparameters appear with equal importance. The model trained using the most optimal hyperparameters is tested with the test set, resulting in a prediction accuracy of 63%. The accuracy for predicting low 'engagement' POIs is higher and the sensitivity for high 'engagement' POIs is much higher than for the other type of POIs. A clear 'overfitting' phenomenon is observed with an accuracy of more than 80% for the training set and hardly any improvement being observed in the validation set prediction throughout the training.

## Conclusions

The CNN model is discarded as it is the least accurate (total accuracy of 60%) and has low sensitivity (57%) for detecting high-engagement POIs. There is no overfitting, so a more complex version of the neural network could be tested by adding layers or neurons to improve its predictive capability.

The models incorporating a pretrained ResNet18 (ResNet18 and FCNN-ResNet18 DB) show severe overfitting. Their predictive performance is inferior compared to other models. Notably, the FCNN-ResNet18 DB model has high sensitivity (84%) for detecting high-engagement POIs. To mitigate overfitting, regularization techniques could be introduced. To enhance prediction, fine-tuning could be applied to train some layers of the ResNet18 network.

The FCNN model achieves one of the highest accuracy rates (67%) and the best sensitivity (85%) for high-engagement POIs. Some overfitting is observed in its training results. Despite its simplicity, its performance in accuracy and sensitivity makes it a strong candidate. To improve it, additional regularization (to reduce overfitting) could be tested, or the model’s complexity could be increased by adding layers/neurons (to boost accuracy).

The best-performing models are the dual-branch architectures (FCNN + CNN branches). Both achieve the highest accuracy (68% and 69%), high sensitivity for high-engagement POIs (73% and 71%), and no overfitting. Further improvements could involve increasing network complexity (e.g., adjusting layers/neurons).
